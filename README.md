A calm, responsive prototype for planning and sharing end-of-life wishes.

## Run locally

Open `index.html` in a browser. The prototype uses plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Included

- Personal planning dashboard and editable farewell wishes
- Example provider directory with search and service filters
- Nominee/contact details
- Private notes and a downloadable wishes summary
- Responsive layout for mobile and desktop

## Important demo limitations

This is a front-end demonstration, not a production end-of-life planning service. Information is stored in the browser's local storage and is not encrypted, backed up, or shared with family members. The demo does not provide account authentication, verified providers, actual bookings, secure document uploads, or emergency support. Provider listings and prices are examples, not recommendations; confirm credentials, availability, and costs directly. Wishes saved here are not a legal document.

Do not enter sensitive personal, financial, or medical information.

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy.yml` publishes the static site to GitHub Pages when changes are pushed to `main`. The first run may take a few minutes to finish.
